# Acesso à VPS

Dados de conexão SSH fornecidos pelo operador:

| Campo | Valor |
|---|---|
| Host | `srv1466565.hstgr.cloud` |
| Usuário | `root` |
| Porta | `22` |

A senha fica fora deste repositório. Armazene-a em um gerenciador de senhas e não a coloque
em arquivos versionados, comandos, scripts ou mensagens. Como a senha foi compartilhada em uma
conversa, troque-a no painel da VPS antes de usá-la. Para uso contínuo, prefira configurar uma
chave SSH e desativar o login SSH por senha quando apropriado.

Checkout confirmado na VPS: `/var/www/html3-current/Republic`. O guia geral de publicação está em
[deploy.md](deploy.md).
